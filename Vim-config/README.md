# My Vim config

This is my [Vim](https://www.vim.org/) configuration — simple as that.



## Config

My Vim config is designed to prioritize feature-rich functionality, even if it means sacrificing some portability, minimalism, and speed.

- **Editor & Visuals:** Displays line numbers, a persistent tab bar, and clean line wrapping.

- **Indentation:** Automates smart formatting and standardizes spacing to 4 spaces.

- **Usability:** Enables full mouse support, extended undo history, and intuitive backspace behavior.



## Setup step by step

1. Install Vim in your terminal if you don't already have it. I recommend installing it using your system's package manager. You can search for a tutorial to do this.

2. Download the [`.vimrc`](.vimrc) file and place it in your home directory:

    <details>
    <summary><i>Windows</i></summary>

    > Place it here: `C:\Users\<YourUser>\.vimrc` *(Replace `<YourUser>` with your actual username)*

    </details>

    <details>
    <summary><i>Linux</i></summary>

    > Place it here: `~/.vimrc`
    
    </details>

    <details>
    <summary><i>macOS</i></summary>

    > Place it here: `~/.vimrc`

    </details>

3. That's it, enjoy!
